Overview

The Cal Poly Universities Rose Float is a student-built entry in the Tournament of Roses Parade. I work on show control: the system that drives the float's hydraulic animation and audio.

7+ hrcontinuous standalone runtime
1unified system for controllers and audio

My role

  • Developed a custom show control program in PowerShell and JavaScript.
  • Integrated Gilderfluke show controllers and audio repeaters into one unified system.
  • Programmed hydraulic animation sequences in Gilderfluke PC-MACs.
  • Tuned hydraulic pressures for smooth, repeatable motion.
  • Engineered standalone operation for animation and audio.

System architecture

A custom program ties the Gilderfluke show controllers and the audio repeaters together so animation and audio run as one show. The float can also run on its own, without the main show control box.
