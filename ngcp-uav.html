Overview

The Northrop Grumman Collaboration Project (NGCP) is a university program in which student teams build and fly unmanned aircraft. I lead the team and built the flight stack and the telemetry backbone.

NGCP is a university collaboration project. It is not employment with Northrop Grumman.

My role

  • Designed a flight stack using Raspberry Pi, Pixhawk and QGroundControl.
  • Optimized data flow over I2C and UART, reducing communication errors by 30%.
  • Built a cost-efficient UAV telemetry backbone using KrakenSDR on Linux.
  • Managed radio direction finding for high-reliability performance and on-time delivery.
  • Prototyped and debugged the embedded flight control stack across all flight test cycles.

Why it matters for show control

A show network and a flight stack share the same hard problems: several controllers that must talk reliably, tight timing, and faults that have to be found fast in the field. The integration and debugging habits I built here are the ones I use on attractions.
