Overview

A modular framework that lets a robot take plain-English commands. An LLM, a database and ROS2 run as a single pipeline, built by a multi-member team that I managed end to end.

< 1 sresponse for pre-mapped commands
100%accuracy on the tested pre-mapped commands

My role

  • Directed end-to-end development of the framework across a multi-member team.
  • Integrated the LLM (Ollama), PostgreSQL and ROS2 into a single pipeline.
  • Built a dual-interpreter command system in Python using Ollama and a rule-based fallback.
  • Designed a PostgreSQL versioning schema that stores motion sequences as JSON and enables full rollback.

System architecture

A typed command goes through two interpreters: an LLM and a rule-based fallback. The resulting motion sequence is stored with a version, then executed through ROS2.
