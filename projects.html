PROJECT 06 Robotics / Software

Natural Language Robotic Control

Directed end-to-end development of a modular robotic control framework that lets a robot take plain-English commands, integrating an LLM (Ollama), PostgreSQL, and ROS2 into a single pipeline across a multi-member team. Built a dual-interpreter command system in Python with an Ollama interpreter plus a rule-based fallback, hitting 100% command accuracy with sub-1-second response for pre-mapped inputs. Designed a PostgreSQL versioning schema that stores motion sequences as JSON, enabling full rollback without touching execution code.

Role: Project Manager
Status: Completed
Scope: 100% accuracy, <1 s response
Python Ollama (LLM) ROS2 PostgreSQL JSON
