Overview

Retro Rewind is a multi-room themed escape experience built like a mini attraction: animatronic characters, synchronized lighting and sound cues, and a central show control system tying every room together. A student team of about 50 designed it, built it, and opened it on campus.

System architecture

The show runs from a custom game master server. An AutomationDirect PLC and more than ten ESP32 devices share one MQTT network, and together they drive the animatronics, lighting and audio and read twelve presence sensors.

Technical contributions

  • Control architecture. Designed the system around an AutomationDirect PLC and 10+ ESP32 devices communicating over MQTT.
  • Game master interface. Designed and built the custom web page the game master uses to monitor and run the rooms in real time.
  • Custom control board. Co-designed a custom PCB for the show with a teammate. Power delivery was simulated in LTspice before layout.
  • Animatronic figures. Designed three characters in Fusion 360 and Maya using marionette principles, and reached fluid motion through iterative prototyping and 3D printing.
  • Cue documentation. Wrote the lighting and sound cue documentation that keeps a multi-room show running on time.
